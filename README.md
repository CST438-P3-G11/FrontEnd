# PlaneSpOtter P3 Group 11
PlaneSpotter Frontend

This is an [Expo](https://expo.dev) project created with [`create-expo-app`](https://www.npmjs.com/package/create-expo-app).

# Description
It shows a UI for PlaneSpotter app which fetches informations in the backend.

# Setup (Get Started)
1. Install dependencies

   ```bash
   npm install
   ```

2. Start the app

   ```bash
   npx expo start
   ```
